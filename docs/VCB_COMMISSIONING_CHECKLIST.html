Standing rules. Props OFF through stage 5.  One person at the E-stop, nobody near the motors; the VCB arms and closes the contactors by itself when both inputs sit at zero for 1 s.  The 20 % thrust limit stays until the control system is tested and tuned under autonomy (gate 6).  Abort rule: anything unexpected (a contactor closes when it should not, a motor moves when it should not, bus_mv disagrees with the meter, a fault you did not provoke) → E-stop, power-cycle the VCB, read the log before going on.  Do not start a stage before the previous gate is signed.

Telemetry fields used (from ~/vcb.json and the raw console)

status: thruster_state (1 IDLE, 2–4 start-up, 5 RUN, 0 FAULT), armed, lsc_closed/hsc_closed, bus_mv, fault_code, estop_24v_present/tsms_24v_present, cmd_source (0 PWM, 1 bench). pwm: chN_us, chN_valid, chN_raw_permille, chN_applied_permille, chN_bad, chN_cmd (signed byte last sent to the converter; ch1 = right motor, ch2 = left). Fault codes: 1 command lost · 2–7 contactor/bus interlock · 8 contactor opened in RUN (latched) · 9 console stop (latched until clear).

What you need on the bench

Jetson: vcb-logger running, ~/vcb.json updating, dashboard :8080   Three terminals: raw console tail, watch cat ~/vcb.json, command shell with vcb()   Pixhawk on USB, mavlink-router :5760, QGC or MAVProxy (stage 4 on)   Multimeter: HV bus at the contactor output; contactor coil feed   BMS reader (battery.json)   Optional: USB-RS485 sniffer on UART5 (38400 8N1)   Optional: servo tester for CONT (3.3 V logic only!)   Tools on the Jetson: vcb_bench_drive.py, vcb_bench_check.py, ap_apply.py
